# 거래 내역 검색 기능 디자인

## 배경

거래 내역이 쌓이면 "저번에 병원 갔을 때 얼마였지?" 같은 니즈가 자연스럽게 생김.
현재 TransactionList는 월별 조회 + 지출/수입 토글만 지원하고 텍스트 검색이 없음.

## 핵심 원칙

- 검색은 **모드 전환** — 월 뷰에서 검색 뷰로 전환, 전체 기간 대상
- **Enter 검색** — 실시간 디바운스 대신 명시적 검색 (한국어 IME 이슈 회피)
- 검색 해제 시 기존 월 뷰로 자연스럽게 복귀

## 1. 검색 진입

TransactionList 상단에 돋보기 아이콘. 터치 시 검색바로 확장.

```
[🍇 3월]  [지출 ▾]  [수입 ▾]  🔍   ← 평소
```

```
🔍 [병원                          ] ✕   ← 검색 모드
[지출/수입 ▾] [카테고리 ▾] [기간: 전체 ▾] [멤버 ▾]
```

- 돋보기 터치 → 검색바 확장 + 키보드 올라옴
- ✕ 터치 → 검색 모드 해제, 기존 월 뷰 복귀
- 멤버 필터는 가구원 2인 이상일 때만 표시

## 2. 검색 범위 & 방식

- **전체 기간** 검색 (월 제한 해제)
- **Enter 키** 또는 돋보기 버튼으로 검색 실행
- 백엔드 서버사이드 검색 (`description ILIKE %keyword%`)
- 결과는 최신순 정렬, 날짜별 그룹

## 3. 필터 칩

검색바 아래에 필터 칩(pill) 배치. 미선택 시 회색, 선택 시 grape 색상.

### 지출/수입
- 전체 (기본) / 지출만 / 수입만

### 카테고리
- 터치 → 바텀시트 (기존 CategoryBottomSheet 패턴 재활용)
- 선택 시 칩에 카테고리명 표시: `[카테고리: 의료 ✕]`

### 기간 (프리셋)
- 전체 (기본) / 최근 1개월 / 최근 3개월 / 최근 6개월 / 올해
- 터치 → 프리셋 목록 드롭다운

### 멤버 (2인+ 가구 전용)
- 터치 → 가구원 목록 드롭다운
- 선택 시 칩에 이름 표시: `[멤버: 남편 ✕]`

## 4. 빈 화면 (검색 모드 진입 직후)

검색어 입력 전 빈 상태에 표시:

```
최근 검색
  병원  ✕
  치킨  ✕
  교통  ✕

자주 쓰는 카테고리
  [🍽 식비] [🏥 의료] [🚗 교통] [☕ 카페]
```

- 최근 검색어: localStorage에 최대 5개 저장, ✕로 개별 삭제
- 카테고리 칩: 사용 빈도 상위 카테고리, 터치 시 해당 카테고리 필터 즉시 적용

## 5. 검색 결과

### 상단 요약
```
"병원" · 12건 · 총 542,000원
```

### 결과 목록
기존 TransactionList와 동일한 형태. 날짜별 그룹 + TransactionItem.

```
3월 15일 (토)
  정형외과 진료    -45,000원  [의료]

1월 8일 (수)
  피부과           -35,000원  [의료]
```

### 카테고리 뱃지 터치 → 필터 적용
결과 내 카테고리 뱃지를 터치하면 해당 카테고리 필터 자동 적용.
필터 칩에도 반영: `[카테고리: 의료 ✕]`

### 빈 결과
```
검색 결과가 없습니다
필터를 초기화하거나 다른 검색어를 시도해보세요.
[필터 초기화]
```

## 6. URL 상태 반영

기존 `useSearchParams` 패턴 확장:

```
?search=병원&type=expense&category=3&period=3m&member=2
```

- `search`: 검색어
- `type`: all | expense | income
- `category`: 카테고리 ID
- `period`: all | 1m | 3m | 6m | year
- `member`: 유저 ID

새로고침 시 검색 상태 유지. 검색 모드 해제 시 파라미터 제거.

## 7. 무한 스크롤

- 첫 로드: 30건
- 스크롤 하단 도달 시 30건 추가 로드
- 백엔드: offset/limit 기반 페이지네이션 (기존 API 패턴)
- 로딩 인디케이터 표시

## 백엔드 변경

### API 파라미터 추가

`GET /api/expenses`, `GET /api/income` 엔드포인트에:

| 파라미터 | 타입 | 설명 |
|---------|------|------|
| `query` | str (optional) | 텍스트 검색 (description ILIKE) |

### DB 인덱스

PostgreSQL `pg_trgm` 확장 + GIN 인덱스 검토 (데이터 많아지면).
초기에는 ILIKE로 충분.

## 서브이슈 구성

1. **BE: 검색 API** — query 파라미터, 합계 엔드포인트
2. **FE: 검색 모드 기본** — 돋보기 진입, 검색바, Enter 검색, 결과 표시, URL 반영
3. **FE: 필터 칩** — 지출/수입, 카테고리, 기간 프리셋, 멤버
4. **FE: 빈 화면 UX** — 최근 검색어 + 카테고리 바로가기
5. **FE: 무한 스크롤** — offset/limit 페이지네이션
6. **FE: 카테고리 뱃지 인터랙션** — 터치 → 필터 적용
