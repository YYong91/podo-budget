# 종합 재무 리포트 페이지 개편 — Design Document

## 배경

현재 InsightsPage는 지출 통계 위주의 단순한 리포트. 자산 탭의 데이터를 활용하지 않고, AI 분석도 LLM에 원시 데이터를 넘기는 방식이라 환각 위험이 있다. 대시보드 제거 후 리포트가 앱의 유일한 분석 페이지가 되므로, 가계부(수입/지출) + 자산을 통합하는 종합 재무 리포트로 개편한다.

## 핵심 결정

- **월간 전용**: 주간/연간 토글 제거. 연간 리포트는 추후 개발
- **자산 탭과의 역할 분리**: 자산 탭 = CRUD/관리, 리포트 = 요약 + 인사이트
- **AI 분석 구조**: 코드가 모든 계산 담당, LLM은 해석만 (환각 방지)
- **법적 준수**: 정보 제공만, 투자 자문 금지 (자본시장법)

## 페이지 구조 (6개 섹션)

### 1. 종합 요약 카드
4개 핵심 지표를 카드로 표시:
- 순자산 (자산 - 부채)
- 수입 합계
- 지출 합계
- 순수익 (수입 - 지출)

각 카드에 전월 대비 변동률 표시. 자산 데이터 없으면 수입/지출만 표시.

### 2. 지출 카테고리 TOP
- 상위 3~5개 카테고리 + 비율 바
- 전월 대비 증감 표시
- 기존 `CategoryBreakdown` 컴포넌트 재활용 또는 리디자인

### 3. 예산 현황
- 전체 예산 대비 지출 진행률 (프로그레스 바)
- 카테고리별 예산 초과/여유 표시
- 기존 `BudgetVsActual` 컴포넌트 활용

### 4. 자산 변동
- 전월 대비 순자산 변동 금액 + 비율
- 유형별 증감 (주식, 예적금, 부동산, 대출 등)
- AssetSnapshot API 활용
- 자산 미등록 시 "자산을 등록하면 더 풍부한 리포트를 볼 수 있어요" CTA

### 5. 이달의 인사이트
- 규칙 기반 하이라이트 (코드로 계산)
- 예: "지난달보다 외식비 30% 증가", "저축률 목표 달성", "예산 초과 카테고리 2개"
- 기존 `MonthlyHighlights` 확장

### 6. AI 심층 분석
버튼 클릭으로 생성. 구조화된 출력:

#### 6a. 재정 건강 점수 (코드 계산)
- 저축률 점수 (수입 대비 저축 비율)
- 지출 관리 점수 (예산 준수율)
- 부채 점수 (부채 비율, 이자율)
- 종합 점수 (가중 평균) + 등급 (A~F)

#### 6b. 핵심 발견 3가지 (LLM)
"What → So What → Now What" 프레임워크:
- What: 어떤 패턴이 보이는지
- So What: 왜 중요한지
- Now What: 어떻게 하면 좋을지

#### 6c. 자산 분석 (LLM)
- 포트폴리오 현황 요약
- 자산 배분 분석
- 일반적인 분산 투자 가이드 (구체적 종목 추천 금지)

#### 6d. 액션 아이템 (LLM)
- 2~3개 구체적 행동 항목
- 실행 가능하고 측정 가능한 내용

#### 6e. 면책 조항 (고정 텍스트)
"이 정보는 일반적인 재무 정보이며, 개인 맞춤 투자 자문이 아닙니다. 투자 결정은 전문가와 상담하세요."

## LLM 입력 데이터 구조

코드에서 사전 계산하여 JSON으로 전달:

```json
{
  "period": "2026-03",
  "household": {
    "income": { "total": 5000000, "categories": [...] },
    "expense": { "total": 3200000, "categories": [...], "top_categories": [...] },
    "budget": { "total": 4000000, "used": 3200000, "over_categories": [...] },
    "savings_rate": 0.36
  },
  "assets": {
    "net_worth": 85000000,
    "total_assets": 100000000,
    "total_liabilities": 15000000,
    "breakdown": { "stock_kr": 30000000, "deposit": 50000000, "real_estate": 20000000 },
    "monthly_change": { "amount": 2000000, "rate": 0.024 },
    "returns": { "stock_kr": 0.05, "stock_us": 0.08 }
  },
  "debt": {
    "loans": [
      { "name": "주택담보대출", "balance": 15000000, "rate": 0.035, "monthly_payment": 500000 }
    ],
    "total_interest_monthly": 43750
  },
  "health_score": {
    "savings": 85,
    "spending": 72,
    "debt": 90,
    "overall": 82,
    "grade": "B+"
  },
  "previous_month": {
    "income": 4800000,
    "expense": 3500000,
    "net_worth": 83000000
  }
}
```

## LLM 프롬프트 설계

- JSON Schema로 구조화된 출력 강제
- 시스템 프롬프트에 한국어 + 법적 경계 명시
- 구체적 종목/금융상품 추천 금지
- "~하는 것이 일반적입니다" 같은 정보 제공 표현 사용

## 기술 스택

- React 19, TypeScript, Tailwind CSS v4
- Chart.js (react-chartjs-2) — 기존 차트 라이브러리 유지
- FastAPI 백엔드 — 새 엔드포인트 또는 기존 확장
- Vitest 테스트
