# 결제수단 & 카드 실적 추적 디자인

## 배경

현재 포도가계부는 지출 기록 시 결제수단 정보가 없다.
카드 실적 달성 여부를 추적하고 싶은 니즈가 있음.

## 핵심 가치

> "삼성카드 이번 달 30만원 채워야 하는데, 지금 얼마 썼지?"

카드사 연동 없이 **결제수단 태깅 + 목표 금액**으로 실적 추적.

## 데이터 모델

### PaymentMethod (결제수단)

| 필드 | 타입 | 설명 |
|------|------|------|
| id | PK | |
| household_id | FK | 가구 소속 |
| name | str | "삼성카드", "현금", "카카오뱅크" |
| type | enum | `credit_card`, `debit_card`, `cash`, `transfer` |
| monthly_target | Decimal(12,2) | 실적 목표 (nullable, 카드만) |
| is_default | bool | 기본 결제수단 여부 |
| color | str | 리포트 차트 색상 (nullable) |

### Expense 모델 변경

- `payment_method_id` FK 추가 (nullable — 기존 데이터 호환)

## 결제수단 등록

**웹(프론트엔드) 설정 페이지에서만** 관리:
- 결제수단 CRUD (이름, 타입, 실적 목표, 기본 여부)
- 봇에서는 등록 불가 — 입력/조회만

## 입력 플로우

3단계 결제수단 결정:

1. **자연어 파싱**: "점심 8000원 삼성카드" → LLM이 payment_method 추출
2. **기본값 적용**: 결제수단 언급 없으면 is_default=True인 결제수단 자동 적용
3. **저장 후 수정**: 응답에 "결제수단 변경" 버튼 제공

### 봇 응답 예시

```
유저: "점심 8000원 삼성카드"
봇:  "✅ 점심 8,000원 저장 (삼성카드 💳)"
     [카테고리 변경] [결제수단 변경] [삭제]

유저: "점심 8000원"  (결제수단 미지정)
봇:  "✅ 점심 8,000원 저장 (삼성카드 💳)"  ← 기본 결제수단 적용
     [카테고리 변경] [결제수단 변경] [삭제]
```

## 실적 현황 조회

### 봇 명령어

트리거: `/card`, "실적", "카드실적"

```
봇:  "💳 3월 카드 실적 현황

     삼성카드: 182,000 / 300,000원 (60%)
     ████████░░░░

     현대카드: 95,000 / 200,000원 (47%)
     ██████░░░░░░

     ⚠️ 삼성카드 118,000원 더 써야 실적 달성!"
```

monthly_target이 설정된 카드만 표시.

### 웹 리포트 페이지

기존 리포트 구조에 "카드 실적" 섹션 추가 (예산 현황 아래):

```
📊 3월 리포트
├── 요약 카드
├── 카테고리 TOP
├── 예산 현황
├── 💳 카드 실적          ← 추가
│   삼성카드  182,000 / 300,000원 (60%) ██████░░░░
│   현대카드   95,000 / 200,000원 (47%) █████░░░░░
├── 자산 변동
├── 건강 점수
└── AI 분석
```

목표 설정된 카드가 없으면 섹션 미표시.

### 웹 설정 페이지

결제수단 목록에 프로그레스 바로 실적 달성률 표시.

## LLM 프롬프트 변경

- 파싱 결과에 `payment_method` 필드 추가
- 등록된 결제수단 목록을 프롬프트 힌트로 전달 (카테고리 힌트와 동일 패턴)

## 변경 범위

| 영역 | 변경 |
|------|------|
| `models/` | PaymentMethod 모델 + Expense에 FK 추가 |
| `alembic/` | 마이그레이션 |
| `schemas/` | PaymentMethod CRUD + Expense 응답에 포함 |
| `api/` | `/api/payment-methods` CRUD 엔드포인트 |
| `api/kakao.py`, `telegram.py` | 결제수단 매칭 + `/card` 명령어 + 결제수단 변경 버튼 |
| `services/llm_service.py` | 프롬프트에 결제수단 힌트 + 파싱 필드 추가 |
| `services/bot_messages.py` | 실적 현황 메시지 템플릿 |
| `frontend/settings` | 결제수단 관리 UI |
| `frontend/insights` | 리포트에 카드 실적 달성률 섹션 |
