# 봇 응답 메시지 전면 리디자인 (#286)

## 목표

bot_messages.py의 모든 응답 메시지를 UX 리서치 기반으로 리디자인하고,
텔레그램/카카오 핸들러의 버튼 UX를 개선하며,
수입 삭제/지출 변환 등 누락된 기능을 추가한다.

## UX 리서치 기반 디자인 원칙

### 1. 톤/보이스: 친근한 존댓말
- "~했어요", "~해볼까요?" 스타일 (포도 캐릭터의 따뜻한 톤)
- 에러 시에도 사용자 탓 안 함 — "제가 잘 이해하지 못했어요"
- 이모지는 메시지 시작/핵심 포인트에만 (과용 금지)

### 2. 메시지 길이 제한
| 유형 | 제한 | 예시 |
|------|------|------|
| 짧은 응답 (확인/에러) | 160자 | 저장 확인, 삭제 확인 |
| 기본 응답 (저장+상세) | 380자 | 저장 + 버튼 안내 |
| 상세 응답 (리포트) | 500자 | TOP 3 요약 (나머지는 "더 보기") |

### 3. 버튼 필수 원칙
- **모든 응답에 다음 행동 버튼 포함** (사용자가 "다음에 뭐 하지?" 하지 않게)
- 주요 옵션 3~5개 (인지 부하 최소화)
- 텔레그램: inline keyboard, 카카오: quick reply

### 4. 3 Strike 에러 처리
- in-memory dict (TTL 30분, 서버 재시작 시 리셋)
- 성공 시 카운트 초기화

### 5. Progressive Disclosure
- 리포트: TOP 3만 기본 노출 → "전체 보기" 버튼
- 예산: 초과/주의만 노출 → "전체 보기" 버튼
- 도움말: 핵심 3개만 → "더 보기" 버튼

## 메시지별 리디자인

### 1. 지출 저장 확인 (`format_expense_saved`)

**현재:**
```
✅ 지출이 기록되었어요!

💰 8,000원
📂 식비
📅 2026-03-20
📝 김치찌개
```

**리디자인:**
```
🍇 김치찌개 8,000원 기록했어요

3월 20일 · 식비
```

변경점:
- 설명+금액을 한 줄에 (핵심 정보 즉시 파악)
- 날짜를 한국어 포맷 ("3월 20일")
- 이모지 최소화
- 버튼: [카테고리 변경] [삭제] [지출→수입 변경]

### 2. 수입 저장 확인 (`format_income_saved`)

## 새 기능

### A. 수입 삭제 (텔레그램)
- `delete_income:{income_id}` callback 핸들러 추가
- handle_callback_query에서 Income 모델도 조회

### B. 지출↔수입 변환
- `convert_to_income:{expense_id}` / `convert_to_expense:{income_id}` callback
- 동작: 원본 삭제 → 같은 금액/설명/날짜로 반대 타입 생성 → 카테고리는 재분류
- 응답: "지출 → 수입으로 변경했어요" + 새 레코드 확인 메시지

### C. 카카오 undo에 수입 지원
- 현재 Expense만 삭제 → Income도 삭제 가능하게
- 가장 최근 기록 (Expense OR Income) 중 최신을 삭제

### D. 3 Strike 에러 카운터
```python
# in-memory, TTL 30분
_error_counts: dict[str, tuple[int, float]] = {}  # key: "{platform}:{user_id}"

def get_strike_count(platform: str, user_id: str) -> int: ...
def increment_strike(platform: str, user_id: str) -> int: ...
def reset_strike(platform: str, user_id: str) -> None: ...
```

## 날짜 한국어 포맷

```python
def format_korean_date(date: datetime) -> str:
    """3월 20일 (목)"""
    weekdays = "월화수목금토일"
    return f"{date.month}월 {date.day}일 ({weekdays[date.weekday()]})"
```

- 오늘이면 "오늘", 어제면 "어제", 그 외는 "3월 20일 (목)"

## 버튼 레이아웃 정리

### 텔레그램 (inline keyboard)

| 상황 | 버튼 |
|------|------|
| 지출 저장 | [카테고리 변경] [삭제] + [수입으로 변경] |
| 수입 저장 | [삭제] [지출로 변경] |
| 삭제 확인 | [삭제 확인] [취소] |
| 카테고리 선택 | 2열 그리드 + [새로 등록] |
| 리포트 | (버튼 없음 — 텍스트 응답) |

### 카카오 (quick reply, 최대 5개)

| 상황 | 버튼 |
|------|------|
| 지출 저장 | [취소] [카테고리 변경] [리포트] |
| 수입 저장 | [취소] [리포트] |
| 에러 1차 | [도움말] |
| 에러 2차 | [도움말] [리포트] |
| 에러 3차 | [도움말] [리포트] [예산] |
| 리포트 | [예산] [도움말] |
| 예산 | [리포트] [도움말] |
