# 봇 가계부 전환 명령어 디자인

## 배경

카카오톡/텔레그램 봇으로 입력한 데이터는 항상 "가장 먼저 가입한 가구"로 들어간다.
가구가 2개 이상인 유저는 봇에서 다른 가계부에 입력할 방법이 없다.

## 접근법

세션 기반 전환 명령어: `/switch` 명령으로 활성 가계부를 DB에 영구 저장.
한 번 바꾸면 이후 모든 입력이 해당 가계부로 들어감.

- 프론트엔드 드롭다운과 동일한 멘탈 모델
- 건별 접두사(`@가계부명`) 방식은 과설계 → 필요 시 추후 추가

## DB 변경

User 모델에 `active_household_id` 컬럼 추가 (nullable FK → households.id).

- `NULL` = 기존 로직 유지 (첫 번째 가입 가구, `joined_at ASC LIMIT 1`)
- 값 있으면 해당 가구 우선 사용
- `get_user_active_household_id_or_none()`이 이 필드를 먼저 확인

## 명령어

| 플랫폼 | 트리거 | 한글 별칭 |
|--------|--------|----------|
| 카카오 | `/switch` | `가계부 전환`, `전환` |
| 텔레그램 | `/switch` | 텍스트로도 `가계부 전환` 가능 |

## 플랫폼별 플로우

### 가구 1개인 경우 (대다수)

```
유저: "가계부 전환"
봇:  "현재 '우리집 가계부'를 사용 중이에요.
      전환할 다른 가계부가 없습니다."
```

### 가구 2개 이상

**카카오톡** — quickReply 방식:

```
유저: "가계부 전환"
봇:  "📋 가계부를 선택하세요.
      현재: 🟢 우리집 가계부

      1️⃣ 우리집 가계부 (현재)
      2️⃣ 혼자쓰는 가계부"
      [quickReply: "1️⃣ 우리집", "2️⃣ 혼자쓰는"]

유저: (터치)
봇:  "✅ '혼자쓰는 가계부'로 전환했어요."
```

**텔레그램** — inline keyboard 방식:

```
유저: /switch
봇:  "📋 가계부를 선택하세요."
      [우리집 가계부 ✓]
      [혼자쓰는 가계부  ]

유저: (버튼 터치)
봇:  (callback → 메시지 수정) "✅ '혼자쓰는 가계부'로 전환했어요."
```

## 현재 가계부 표시

지출 저장 응답에 가구가 2개 이상인 유저에 한해 가계부명 표시:

```
✅ 점심 8,000원 저장 (🏠 우리집 가계부)
```

가구 1개면 기존과 동일 (표시 안 함).

## 변경 범위

| 파일 | 변경 |
|------|------|
| `models/user.py` | `active_household_id` 컬럼 추가 |
| `alembic/` | 마이그레이션 1개 |
| `api/dependencies.py` | `get_user_active_household_id_or_none` 수정 — active_household_id 우선 참조 |
| `api/kakao.py` | `/switch` 핸들러 + COMMAND_ALIASES 추가 |
| `api/telegram.py` | `/switch` 핸들러 + callback 처리 추가 |
| `services/bot_messages.py` | 전환 관련 메시지 템플릿 |

프론트엔드 드롭다운 연동은 별도 이슈로 분리 (현재는 봇만).
