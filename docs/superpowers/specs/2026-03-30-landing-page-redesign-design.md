# 포도가계부 랜딩페이지 리디자인

## 개요

기존 프로토타입 수준의 랜딩페이지(`LandingPage.tsx`)를 대체하는, 본격적인 서비스 소개 랜딩페이지.
v0.dev를 활용해 디자인을 생성하고, 결과물을 기존 프로젝트에 통합한다.

## 목적

- 앱 소개 + 회원가입(로그인) 유도
- 핵심 차별점(자연어 입력, 메신저 연동)을 명확히 전달
- 기존 `/` 경로의 LandingPage를 대체

## 디자인 방향

- **톤앤매너**: 따뜻하고 친근한 — 둥근 모서리, 포도 일러스트, Grape 디자인 시스템 컬러
- **레이아웃**: 풀페이지 스크롤 — 섹션별로 화면을 채우며 스토리텔링
- **좌우 교차 레이아웃**: 섹션 2↔3↔4가 텍스트/이미지 위치를 교차
- **이미지**: 실제 앱 스크린샷 사용 (섹션 2 채팅 목업 제외)
- **CTA**: "시작하기" → `/login` (Supabase Auth, Google OAuth)

## 컬러 팔레트 (Grape 디자인 시스템)

| 용도 | 값 |
|------|----|
| Primary (Grape Purple) | `#9333ea` |
| Income (Leaf Green) | `#16a34a` |
| Light Background (Cream) | `#fefce8` |
| Dark Background | `#1c1917` |
| 폰트 | Pretendard (한국어) |

## 섹션 구성

### 섹션 1: 헤더 + 히어로

**헤더**
- 좌: 포도 아이콘 + "포도가계부" 로고
- 우: "로그인" 버튼

**히어로**
- 메인 카피: "포도알처럼 하나씩, 알찬 가계부"
- 서브 카피: "말로 기록하면 AI가 알아서 분류하는 우리 집 가계부"
- CTA: "지금 시작하기" 버튼 (grape-600, 둥근 모서리)
- 우측: 앱 메인 화면(TransactionList) 스크린샷을 폰 목업 안에 배치
- 배경: 크림색 기반, 포도 보라색 그라데이션 포인트

### 섹션 2: 메신저 연동 (핵심 차별점)

- **소제목**: "채팅으로 기록하세요"
- **설명**: "카카오톡이나 텔레그램에서 '점심 김치찌개 8000원' 한 줄이면 끝. AI가 카테고리, 날짜, 결제수단까지 알아서 분류합니다."
- **레이아웃**: 좌측 텍스트 + 우측 채팅 UI 목업
- **이미지**: 실제 메신저 UI가 아닌, 포도가계부 Grape 스타일의 채팅 목업 (상표권 이슈 회피 + 메신저 비한정 느낌)
- 입력 → AI 파싱 결과 프리뷰 흐름이 한눈에 보이도록

### 섹션 3: 공유 가계부

- **소제목**: "가족과 함께 쓰는 가계부"
- **설명**: "가구를 만들고 가족을 초대하세요. 누가 얼마를 썼는지 한눈에, 하나의 가계부를 함께 기록할 수 있어요."
- **레이아웃**: 좌측 스크린샷 + 우측 텍스트 (섹션 2와 교차)
- **이미지**: 거래 목록에 기록자(멤버 이름/아바타)가 표시된 화면 스크린샷
- **선행 작업**: 거래 목록에 기록자 표시 기능 구현 필요

### 섹션 4: 돌아보기

- **소제목**: "이달의 소비를 돌아보세요"
- **설명**: "카테고리별 지출, 예산 대비 현황, 건강 점수까지. 우리 가계부의 흐름을 한눈에 파악할 수 있어요."
- **레이아웃**: 좌측 텍스트 + 우측 스크린샷 (섹션 3과 교차)
- **이미지**: InsightsPage(돌아보기) 화면 스크린샷 — 차트, 건강 점수, 카테고리 TOP 등

### 섹션 5: 편의기능 모음

- **소제목**: "꼼꼼하게, 더 편리하게"
- **레이아웃**: 5개 카드 그리드
- 스크린샷 없이 아이콘 + 제목 + 한줄 설명
- "기능이 많다"는 신뢰감을 주는 역할

| 기능 | 한줄 설명 |
|------|----------|
| 예산 관리 | 카테고리별 예산 설정, 초과 시 알림 |
| 정기결제 | 매달 반복되는 지출 자동 기록 |
| 결제수단 | 카드·현금·계좌별 관리 |
| 자산 현황 | 내 자산의 흐름을 한눈에 |
| 카테고리 | 나만의 카테고리로 분류 |

### 섹션 6: 마지막 CTA + 푸터

**CTA**
- 카피: "포도알처럼 하나씩, 지금 시작하세요"
- 큰 "시작하기" 버튼 → `/login`
- 배경: 포도 보라색 그라데이션 (히어로와 호응)

## 구현 방식

1. **v0.dev에서 디자인 생성**: 이 스펙 기반으로 v0 프롬프트 작성 → 결과물 생성
2. **결과물 통합**: v0 결과 코드를 `LandingPage.tsx`에 통합
3. **실제 스크린샷 교체**: v0 생성 시 placeholder 이미지 → 이후 실제 앱 스크린샷으로 교체
4. **선행 작업**: 거래 목록 기록자 표시 기능 구현 (섹션 3용)

## 기술 제약

- React 19 + TypeScript + Tailwind CSS v4
- Grape 디자인 시스템 컬러 변수 사용
- 모바일 퍼스트 반응형 (기본 모바일 → md/lg 확장)
- 다크모드 지원 (class 기반 `.dark`)
- 기존 라우팅 유지: `/` 경로, 로그인 시 `/home`으로 리디렉션
