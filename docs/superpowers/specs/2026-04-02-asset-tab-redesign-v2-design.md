# 자산탭 리디자인 v2 — 디자인 스펙

## 배경

기존 자산 탭(2026-03-14 디자인)은 순자산 히어로 + 프로그레스 바 + 라인차트 + 유형별 그룹으로 구성되어 있다. 사용은 가능하지만 다음 문제가 있다:

- **동기부여 부재**: 장기 목표(예: 10억) 대비 프로그레스 바가 거의 안 움직여서 변화를 체감할 수 없음
- **변화 원인 불명**: "지난달 대비 +48만원"만 보여주고 왜 올랐는지/내렸는지 알 수 없음
- **저축 데이터 부정확**: 수입-지출을 저축으로 표시하지만 실제 저축은 저축성지출 카테고리에 기록됨
- **업데이트 넛지 과잉**: 시세 자동 갱신 자산에도 업데이트 촉구가 뜸
- **빈 상태 미흡**: 자산 0개일 때 온보딩 경험이 없음
- **차트 비역동적**: Y축 범위가 넓어 변동이 직선처럼 보임

## 핵심 가치

> **"내 자산을 쉽게 기록하고, 변화를 한눈에 보고, 성장하는 재미를 느끼는 곳"**

키워드: **현황 파악 / 동기부여 / 간편 기록**

## 화면 구조 (위→아래)

### 1. 순자산 히어로

순자산 한 숫자를 최상단에 크게 표시. 정보 전달에 집중하며 액션 버튼은 제거한다.

**구성:**
- 순자산 (큰 숫자, 3xl bold)
- 전월 대비 변화량 (leaf-600 양수 / rose-600 음수)
- 자산/부채 소계 한 줄 (xs 텍스트)

**변경점 (기존 대비):**
- "계좌 관리" / "자산 등록" 버튼 제거 → 자산 목록 그룹 헤더 "+" 버튼으로 이동
- 월 저축 요약 별도 카드 제거 → 변화량 분해 안에 포함

---

### 2. 이번 달 성과 카드

동기부여의 핵심 섹션. 매달 체감 가능한 변화량과 그 원인을 보여준다.

**구성:**
- 이번 달 순자산 변화량 (크게, leaf-600 / rose-600)
- 스트릭 뱃지: "3개월 연속 순자산 증가 중" (스냅샷 연속 증가 개월 수)
- "변화 상세" 접이식 영역 (기본 접힘, 탭하면 펼침)

**변화량 분해 (접이식 내부):**
```
저축         +50만원
투자 수익    +32만원
대출 상환    +90만원
부동산       -124만원
```

- 데이터 소스 2개를 프론트에서 합산:
  1. **스냅샷 breakdown 차이**: 이번 달 스냅샷 `breakdown` vs 전월 스냅샷 `breakdown`
  2. **저축 API**: `/api/assets/monthly-savings`에서 저축성지출 합산
- `breakdown`은 Text 컬럼에 JSON 문자열로 저장됨. API 응답 시 `dict[str, float] | None`으로 파싱 제공.
- breakdown JSON 키는 Asset type 코드: `{"stock_kr": 5000000, "stock_us": 3000000, "deposit": 10000000, "real_estate": 50000000, "loan": -20000000}`
- 프론트에서 표시 그룹으로 매핑:
  | 표시 라벨 | breakdown 키 |
  |----------|-------------|
  | 투자 | stock_kr + stock_us + crypto |
  | 예적금 | deposit |
  | 부동산/기타 | real_estate + other |
  | 대출 | loan (부호 반전: 잔액 감소 = 양수 표시) |
  | 저축 | monthly-savings API (breakdown에 없음) |
- 변화량 0인 항목은 숨김

**순자산 감소 시 프레이밍:**
- 변화량은 빨간색으로 정직하게 표시
- 스트릭 영역에 긍정 요소가 있으면 강조: "대출 잔액이 90만원 줄었어요", "저축은 꾸준히 유지 중"
- 긍정 요소가 하나도 없으면 스트릭 영역을 숨김 (억지 위로 X)

**스트릭 판정 로직 (프론트엔드):**
1. 스냅샷을 최신→과거 순으로 순회
2. 연속으로 전월 대비 순자산이 증가한 개월 수 카운트
3. 2개월 이상이면 "{N}개월 연속 순자산 증가 중" 표시
4. 감소 시: breakdown에서 양수 변화 항목을 찾아 긍정 메시지 생성

### 3. 마일스톤 프로그레스

장기 목표를 단기 마일스톤으로 분해하여 매달 성취감을 느끼게 한다.

**구성:**
- "다음 목표: 2억 5,000만원" 타이틀
- 미니 프로그레스 바 + 퍼센트
- "340만원 남았어요" 남은 금액
- 마일스톤 트레일: ● 달성 / ◐ 진행 중 / ○ 미달성 (최근 2~3개 + 현재 + 다음 1~2개)
- 우측 상단: "최종 목표 10억 · 2030년" 작은 텍스트 (탭하면 목표 설정 모달)

**마일스톤 단위 자동 결정 (프론트엔드):**
| 순자산 범위 | 마일스톤 단위 |
|------------|-------------|
| 1억 미만 | 500만원 |
| 1억~5억 | 1,000만원 |
| 5억 이상 | 5,000만원 |

**프로그레스 계산:**
- 다음 마일스톤 = `ceil(순자산 / 단위) * 단위`
- 이전 마일스톤 = 다음 마일스톤 - 단위
- 프로그레스 = `(순자산 - 이전 마일스톤) / 단위 * 100`

**달성 시:**
- 축하 메시지: "2억 5,000만원 돌파!" (토스트 또는 인라인)
- 자동으로 다음 마일스톤(3억)으로 전환

**목표 미설정 시:**
- "순자산 목표를 설정하면 마일스톤이 생겨요" CTA
- 탭하면 기존 목표 설정 모달

**기존 AssetGoal 모델/API 변경 없음.** 프론트에서 마일스톤 계산만 추가.

### 4. 순자산 추이 차트

기존 정적 라인차트를 인터랙티브하게 개선한다.

**변경점:**

1. **기간 선택 탭**: 3개월 / 6개월 / 1년 (기본값: 6개월)
2. **Y축 자동 스케일링**: 해당 기간 내 최소~최대 기준 (상하 10% 여백)
3. **영역 차트(area)**: 선 아래 grape 그라데이션 fill
4. **탭 인터랙션**: 특정 월 탭 → 툴팁에 순자산 + 전월 대비 변화량
5. **기간 요약**: 차트 하단에 "6개월간 +280만원" 한 줄
6. **목표선 제거**: 마일스톤 섹션으로 분리했으므로 차트는 순수 추이만

**데이터 부족 시:**
- 스냅샷 1개 이하: 차트 숨김 + "다음 달부터 추이를 볼 수 있어요" 안내
- 스냅샷 2~3개: 3개월 탭만 활성, 나머지 비활성(disabled)

### 5. 자산 목록 (유형별 그룹)

기존 유형별 그룹핑 구조 유지. 두 가지 기능 추가.

**그룹 헤더 "+" 버튼:**
- 각 그룹 헤더 우측에 "+" 아이콘 버튼
- 탭 → 해당 유형이 사전 선택된 `/assets/new?type=XXX`로 이동
- 투자 → type=stock_kr, 예적금 → type=deposit, 부동산/기타 → type=real_estate, 부채 → type=loan

**대출 상환 진척도 (선택적):**
- Asset 모델에 `original_amount: Numeric(18,2), nullable` 필드 추가
- 대출 등록/수정 폼에 "원래 대출금" 필드 추가 (선택적, 입력 안 해도 됨)
- `original_amount` 값이 있는 대출 항목:
  - 미니 프로그레스 바 표시
  - "원금 2억 중 1억 2,200만원 상환 (61%)"
  - 상환액 = original_amount - current_value (manual_value)
- 값이 없으면: 기존처럼 잔액만 표시

**기존 유지:** 접기/펼치기, AssetRow 링크, 수익률 표시, 유형 그룹 정의

---

### 6. 업데이트 넛지

수동 자산만 대상으로 스마트하게 표시한다.

**대상 판별:**
- 시세 자동 갱신 자산 (stock_kr, stock_us, crypto) **제외**
- deposit, real_estate, other, loan 중 `updated_at`이 30일 이상 경과한 항목만 대상
- 대상 0개 → 넛지 카드 미표시

**카드 구성:**
- "자산 현황을 업데이트해보세요"
- 대상 자산명 나열 (예: "신한 적금, 아파트")
- 탭 → 첫 번째 대상 자산의 수정 페이지로 이동

---

### 7. 빈 상태 온보딩

자산 0개일 때 대시보드 자체가 온보딩 역할을 한다.

**조건:** `assets.length === 0`

**표시 내용:**
- 히어로/성과 카드/차트/목록 **전부 숨김**
- "우리 가족 자산을 정리해볼까요?" 메시지
- 자산 유형 선택 카드 그리드 (2x3):
  - 예적금, 주식, 코인, 부동산, 기타, 대출
  - 각 카드에 아이콘 + 라벨
  - 탭 → 해당 타입 사전 선택된 `/assets/new?type=XXX`
- "하나만 등록하면 바로 순자산이 보여요" 안내 문구

**1개 등록 후:** 대시보드로 복귀하면 즉시 순자산 히어로가 보임 (온보딩 → 대시보드 자연 전환)

## API 변경

### `/api/assets/monthly-savings` — 로직 변경

**현재:** 이번 달 수입 합계 - 이번 달 지출 합계

**변경:** 이번 달 지출 중 `Category.is_savings == true`인 카테고리에 속하는 항목 합산

```python
# 저축성 지출 카테고리 ID 조회
savings_cat_ids = select(Category.id).where(
    Category.is_savings == True,
    Category.household_id == hid,
)

# 이번 달 저축성 지출 합산
savings_total = select(func.coalesce(func.sum(Expense.amount), 0)).where(
    Expense.household_id == hid,
    Expense.date >= first_of_month,
    Expense.date <= today,
    Expense.category_id.in_(savings_cat_ids),
)
```

**응답 변경:**
```json
{ "month": "2026-04", "savings": 500000 }
```

- `month` 필드: 기존 별도 `year`/`month` 정수 → `"YYYY-MM"` 문자열로 통합
- 기존 `total_income`, `total_expense`, `net_savings` 필드 제거
- 프론트 `MonthlySavings` 타입도 동일하게 변경: `{ month: string; savings: number }`
- `AssetDashboard`에서 `monthlySavings.net_savings` 참조를 `monthlySavings.savings`로 전환

### 기타 API — 변경 없음

AssetGoal CRUD, Asset CRUD, snapshots, summary 모두 기존 유지.
