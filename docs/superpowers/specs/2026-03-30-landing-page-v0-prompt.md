# v0 프롬프트 — 포도가계부 랜딩페이지

아래 프롬프트를 v0.dev에 붙여넣어 사용합니다.

---

AI 기반 가계부 서비스 "포도가계부"의 랜딩페이지를 만들어줘. React + Tailwind CSS 기반이야.

## 디자인 톤

- 따뜻하고 친근한 느낌. 둥근 모서리, 부드러운 그림자, 여유 있는 여백.
- 한국어 서비스야. 모든 텍스트는 한국어로.
- 폰트: Pretendard (Google Fonts에서 import)
- 풀페이지 스크롤 랜딩. 각 섹션이 화면을 가득 채우고, 스크롤할 때마다 새 섹션이 등장하는 느낌.
- 스크롤 시 섹션이 자연스럽게 fade-in 되는 애니메이션 적용.

## 컬러

- Primary (보라색): #9333ea
- Primary hover: #7e22ce
- 배경 (크림): #fefce8
- 카드 배경: white
- 텍스트 (메인): #1c1917
- 텍스트 (서브): #78716c
- 수입/긍정 (초록): #16a34a

## 섹션 구성 (총 6개 섹션)

### 1. 헤더 + 히어로

**헤더** (상단 고정, 스크롤 시 배경 블러)
- 좌측: 앱 로고 이미지(placeholder로 보라색 원형 아이콘) + "포도가계부" 텍스트 (bold, 보라색)
- 우측: "로그인" 버튼 (보라색 아웃라인 스타일, 둥근 모서리)

**히어로**
- 메인 카피: "포도알처럼 하나씩, 알찬 가계부" (text-3xl md:text-5xl, bold)
- 서브 카피: "말로 기록하면 AI가 알아서 분류하는 우리 집 가계부" (text-base md:text-lg, 서브 텍스트 컬러)
- CTA 버튼: "지금 시작하기" (보라색 배경, 흰 텍스트, rounded-xl, 큰 패딩, hover 시 살짝 어두워짐)
- 우측에 스마트폰 목업 안에 앱 메인 화면 스크린샷 placeholder (회색 박스에 "앱 스크린샷" 텍스트)
- 모바일에서는 텍스트 위 + 폰 목업 아래로 세로 배치
- 배경: 크림색 기반, 상단에 보라색 → 크림색 그라데이션 블롭 장식

### 2. 메신저 연동 (핵심 차별점)

- 소제목: "채팅으로 기록하세요" (text-2xl md:text-4xl, bold)
- 설명: "카카오톡이나 텔레그램에서 '점심 김치찌개 8000원' 한 줄이면 끝. AI가 카테고리, 날짜, 결제수단까지 알아서 분류합니다."
- 레이아웃: 좌측 텍스트 + 우측 채팅 UI 목업
- 채팅 목업은 실제 메신저를 모방하지 않고, 보라색 테마의 자체 채팅 UI로 디자인:
  - 유저 말풍선 (우측, 밝은 보라): "점심 김치찌개 8000원"
  - 봇 응답 말풍선 (좌측, 흰색 카드): 파싱 결과 프리뷰 — 카테고리: 식비, 금액: 8,000원, 날짜: 오늘, "저장되었습니다 ✓"
  - 유저: "어제 택시 15000원 카드로"
  - 봇: 카테고리: 교통, 금액: 15,000원, 결제수단: 카드, "저장되었습니다 ✓"
- 모바일에서는 세로 배치 (텍스트 위, 채팅 목업 아래)

### 3. 공유 가계부

- 소제목: "가족과 함께 쓰는 가계부" (text-2xl md:text-4xl, bold)
- 설명: "가구를 만들고 가족을 초대하세요. 누가 얼마를 썼는지 한눈에, 하나의 가계부를 함께 기록할 수 있어요."
- 레이아웃: 좌측 스크린샷 placeholder + 우측 텍스트 (섹션 2와 좌우 교차)
- 스크린샷 placeholder: 거래 목록에 멤버 아바타/이름이 표시된 가계부 화면 (회색 박스에 "공유 가계부 스크린샷" 텍스트)
- 모바일에서는 세로 배치 (텍스트 위, 스크린샷 아래)

### 4. 돌아보기

- 소제목: "이달의 소비를 돌아보세요" (text-2xl md:text-4xl, bold)
- 설명: "카테고리별 지출, 예산 대비 현황, 건강 점수까지. 우리 가계부의 흐름을 한눈에 파악할 수 있어요."
- 레이아웃: 좌측 텍스트 + 우측 스크린샷 placeholder (섹션 3과 좌우 교차)
- 스크린샷 placeholder: 차트와 통계가 보이는 리포트 화면 (회색 박스에 "돌아보기 스크린샷" 텍스트)
- 모바일에서는 세로 배치

### 5. 편의기능 모음

- 소제목: "꼼꼼하게, 더 편리하게" (text-2xl md:text-4xl, bold, 중앙 정렬)
- 5개 카드 그리드 (모바일 1열, md 2열, lg 3열)
- 각 카드: 아이콘 + 제목 + 한줄 설명, 흰 배경, 둥근 모서리, 부드러운 그림자
- 카드 목록:
  1. 아이콘: 💰 / 제목: "예산 관리" / 설명: "카테고리별 예산 설정, 초과 시 알림"
  2. 아이콘: 🔄 / 제목: "정기결제" / 설명: "매달 반복되는 지출 자동 기록"
  3. 아이콘: 💳 / 제목: "결제수단" / 설명: "카드·현금·계좌별 관리"
  4. 아이콘: 📊 / 제목: "자산 현황" / 설명: "내 자산의 흐름을 한눈에"
  5. 아이콘: 🏷️ / 제목: "카테고리" / 설명: "나만의 카테고리로 분류"

### 6. 마지막 CTA + 푸터

**CTA 섹션**
- 배경: 보라색 그라데이션 (#9333ea → #7e22ce)
- 카피: "포도알처럼 하나씩, 지금 시작하세요" (흰 텍스트, text-2xl md:text-4xl, bold)
- "시작하기" 버튼 (흰 배경, 보라색 텍스트, rounded-xl, 큰 패딩)

**푸터**
- 배경: 크림색
- 좌측: 개인정보처리방침 | 이용약관 (링크)
- 우측: © 2026 포도가계부
- 모바일에서는 세로 중앙 정렬

## 반응형

- 모바일 퍼스트. 기본은 모바일(세로 배치), md 이상에서 좌우 레이아웃.
- 히어로 및 기능 섹션의 텍스트+이미지 배치가 모바일에서는 세로로 자연스럽게 전환.

## 추가 요구사항

- 다크모드는 일단 제외. 라이트 모드만.
- 스크린샷 자리는 placeholder(회색 박스)로 비워두되, 실제 이미지로 교체하기 쉬운 구조로.
- 부드럽고 고급스러운 느낌. 네카라쿠배 신규 서비스 런칭 랜딩페이지 수준의 퀄리티.
